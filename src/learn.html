STEP 01 / 08

Choose one language and run a program

Pick one language for this path. Learn its entry point, basic syntax, and how to read an error. Use JavaScript for the supported Tracecode runtime; use a local toolchain for other languages.

Try it yourself

Write a program that prints your name and a learning goal. Run it, introduce a syntax error, then fix it.

Ask AI after your first attempt

Explain this error in plain language. Give me one hint, not the corrected program.

Check your understanding

  1. What is the difference between source code and output?

    Reveal self-check answer

    Source code is the instruction text; output is what the executed program produces.

  2. Why does code that looks correct sometimes fail before producing output?

    Reveal self-check answer

    Syntax or compilation errors can prevent execution. Read the location and message, then inspect nearby code.

  3. Can you run your greeting again without copying it?

    Reveal self-check answer

    Self-check: recreate it from memory, change the message, and explain how the output changes.

STEP 02 / 08

Values, types, and variables

Learn numbers, strings, booleans, assignment, and expressions. Check your chosen language’s conversion and mutability rules.

Try it yourself

Store a price of 80 and a quantity of 3. Calculate and print the total. Change the quantity and predict the result first.

Ask AI after your first attempt

Ask me to predict three expressions in my chosen language. Explain each only after I answer.

Check your understanding

  1. What is 80 multiplied by 3?

    Reveal self-check answer

    240. Changing quantity to 4 makes the total 320.

  2. Why might a string containing 5 behave differently from the number 5?

    Reveal self-check answer

    A string represents text. Operators may concatenate, convert, or reject it depending on the language.

  3. Does changing a variable automatically recalculate another variable assigned earlier?

    Reveal self-check answer

    Usually no for ordinary eager assignments: the earlier expression was already evaluated. Reassign the result to recalculate it.

STEP 03 / 08

Conditions and loops

Learn comparisons, branching, loop conditions, and how updates move a loop toward stopping.

Try it yourself

Sum the even numbers from 1 through 10. Write down the running total at every iteration.

Ask AI after your first attempt

Review my loop condition and give a counterexample if it is wrong. Do not rewrite the loop.

Check your understanding

  1. What total should the even-number program produce?

    Reveal self-check answer

    30: 2 + 4 + 6 + 8 + 10.

  2. How do less-than and less-than-or-equal change a loop ending at 10?

    Reveal self-check answer

    Less-than excludes 10; less-than-or-equal includes it when the loop reaches that value.

  3. How can a while loop run forever?

    Reveal self-check answer

    Its condition never becomes false, for example because the controlling value is never updated in the required direction.

STEP 04 / 08

Functions, scope, and recursion

Break a problem into functions with inputs and return values. Trace local variables and calls before trying recursion.

Try it yourself

Write factorial for nonnegative integers with factorial(0) = 1. Trace factorial(4), including every return.

Ask AI after your first attempt

Ask me to explain the base case and each return in my solution. Point out one gap in my explanation.

Check your understanding

  1. What does factorial(4) return?

    Reveal self-check answer

    24. The multiplication chain is 4 × 3 × 2 × 1.

  2. Why does recursion need a base case and progress toward it?

    Reveal self-check answer

    The base case stops calls; progress makes that case reachable. Without either, calls may continue until a limit is hit.

  3. Are a function’s local variables shared by every recursive call?

    Reveal self-check answer

    Ordinary local bindings belong to each call. Referenced objects or external state can still be shared.

STEP 05 / 08

Collections, objects, and references

Practice indexing, iteration, mutation, and copying. Investigate how your language represents arrays and objects.

Try it yourself

Find the maximum in [4, 2, 9, 1]. Decide what your function should do for an empty collection.

Ask AI after your first attempt

Give me edge cases for my collection function. Wait for my predictions before showing expected results.

Check your understanding

  1. What is the maximum of [4, 2, 9, 1]?

    Reveal self-check answer

    9. A one-pass scan can keep the largest value seen so far.

  2. Why is initializing the maximum to zero unsafe?

    Reveal self-check answer

    For an all-negative collection, zero may not be an element and is larger than the true maximum. Initialize from the first element after handling empty input.

  3. In JavaScript, if b = a for an array, does changing b[0] affect a[0]?

    Reveal self-check answer

    Yes: both variables refer to the same array. Assignment does not copy the array.

STEP 06 / 08

Algorithms and data structures

Start with a direct solution, then compare time and space costs. Learn searching, stacks, queues, and maps through small examples.

Try it yourself

Implement binary search on [1, 3, 5, 7, 9]. Trace the bounds while finding 7, then search for 6.

Ask AI after your first attempt

Compare my direct solution with my improved solution. Ask me to justify the time and extra-space costs.

Check your understanding

  1. What precondition does ordinary binary search need?

    Reveal self-check answer

    The collection must be sorted consistently with the comparisons used by the search.

  2. What should the searches for 7 and 6 return with zero-based indexing and -1 for missing values?

    Reveal self-check answer

    7 is at index 3; 6 is absent, so return -1.

  3. Why is binary search O(log n)?

    Reveal self-check answer

    Each iteration discards roughly half the remaining search interval, so the iteration count grows logarithmically.

STEP 07 / 08

Debug, test, and review AI-generated code

Treat generated code as a proposal. Read it, predict behavior, test normal and boundary inputs, and verify unfamiliar APIs in official documentation.

Try it yourself

Review a maximum-finding function initialized to zero. Add tests for negative numbers, one item, duplicates, and empty input.

Ask AI after your first attempt

Here is my code and expected behavior. Identify a failing input and explain why it fails before suggesting a fix.

Check your understanding

  1. Is passing one example enough to trust a solution?

    Reveal self-check answer

    No. It only establishes behavior for that example; boundary cases and other input classes can expose defects.

  2. What should you do if AI suggests an unfamiliar function or package API?

    Reveal self-check answer

    Check the official documentation for the version you use and run a minimal example. Do not assume the suggested API exists.

  3. What demonstrates that you understand an AI-assisted solution?

    Reveal self-check answer

    You can explain each step, predict new outputs, write tests, and reproduce or modify the approach without copying blindly.

STEP 08 / 08

Build a small project and contribute

Combine the fundamentals into something useful. Describe requirements, split the work, test behavior, and explain your decisions in a README.

Try it yourself

Build an expense tracker that adds entries, totals amounts, filters by category, and rejects invalid amounts. Then propose one focused improvement to Tracecode.

Ask AI after your first attempt

Review my requirements and tests. Ask about missing behavior and tradeoffs; let me implement the changes.

Check your understanding

  1. What should your tracker do with a negative amount or an empty category?

    Reveal self-check answer

    Choose and document the rules before implementation. For this exercise, reject negative amounts and require a nonempty category.

  2. What should a focused pull request explain?

    Reveal self-check answer

    The problem, the change, expected behavior, checks performed, and remaining limitations. Include screenshots for interface changes.

  3. When are you ready to move on?

    Reveal self-check answer

    You can demonstrate the project, explain its data flow, handle specified edge cases, and make a small change without having AI regenerate everything.
